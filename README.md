# DiscordBot
 
Discord-бот для автоматизації навчального процесу.

## Можливості

-  Створення та керування завданнями
-  Нагадування про дедлайни
-  Статистика виконання завдань
-  Адміністративні команди
-  Збереження даних у SQLite

## Технології

- Python 3.12
- discord.py
- SQLite
- dotenv
